# Architecture Decision Log

Use this file for durable decisions that future AI-assisted sessions need to preserve.

Do not record trivial implementation details.

Template:

```text
# Decision: <title>

Date: YYYY-MM-DD
Status: accepted | superseded

## Context

What problem or uncertainty existed?

## Decision

What did we choose?

## Why

Why is this the smallest/best choice for the current product stage?

## Consequences

What becomes easier, harder, or constrained because of this decision?
```
